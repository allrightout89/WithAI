회원, 레슨 기록, 운동 라이브러리를 JSON 파일로 내려받습니다. PC 변경 또는 브라우저 초기화 전에 백업하세요.

데이터 복원

이전에 내려받은 JSON 백업 파일을 선택하면 현재 브라우저 데이터가 백업 데이터로 교체됩니다. 복원 전 현재 데이터도 백업하세요.

현재 버전의 범위와 보안 안내

  • 로그인 및 관리자 데이터 스냅샷은 Supabase 클라우드에 연결됩니다.
  • 현재 HTML의 관리자 운영 데이터는 단일 JSON 스냅샷으로 동기화됩니다.
  • 회원·트레이너 전용 화면과 세부 기능은 후속 단계에서 연결해야 합니다.
  • 실제 회원의 연락처, 건강정보, 얼굴이 포함된 영상은 테스트 버전에 입력하지 않는 것을 권장합니다.
  • 실서비스 전에는 서버 암호화, 계정 권한, 동의 및 개인정보 처리 절차가 필요합니다.
